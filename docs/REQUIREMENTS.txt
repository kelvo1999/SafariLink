For intermediate stops, model each journey as adjacent route segments.
A seat booked Nairobi–Naivasha may be sold Naivasha–Nakuru, but may not simultaneously be sold Nairobi–Nakuru.
Use transactions, row locking, and unique per-trip/per-seat/per-segment allocation constraints, or an equally robust design.
Enforce these rules in the database and server, not only in the browser.
Hold expiry must work during booking requests even if the cleanup worker is delayed.
Use server time for expiry; the browser countdown is only a display.
